# 🧠🍽️ AI-Powered Meal Planner

An intelligent **meal planning web application** that helps users generate meal ideas and full weekly meal plans based on the **ingredients they already have** — powered by **Google Gemini AI**.

Built using **Node.js**, **Express**, **PostgreSQL**, and **EJS**, the app provides a seamless experience for planning, saving, and managing meals — with secure authentication and cookie-based sessions.

---

## 🌟 Features

✅ **AI-Generated Meal Plans**
- Uses **Google Gemini API** to suggest meals or full week meal plans.
- Supports **single meal** or **weekly plan** generation.
- Adapts to ingredients entered by the user.

✅ **Smart Ingredient Input**
- Users can input available ingredients.
- Gemini suggests matching recipes with preparation steps and nutritional insights.

✅ **User Authentication**
- Full authentication system using **cookies**:
  - Register, Sign In, and Sign Out
  - Secure session management
  - Only logged-in users can generate or save meal plans

✅ **Meal Plan Management**
- Save generated plans to the database (PostgreSQL)
- View, edit, or delete saved plans

✅ **Elegant UI**
- Built with **EJS** templates and **modern JavaScript**
- Clean, responsive, and minimal design
